## 二开功能

- OpenAI 用量按最终出站档位计费。账号继续支持强制 Fast、免费 Fast 和免费 Ultra Fast，两个免费开关按各自档位重算 Standard 客户扣费，并保留实际档位和对应的总费用。
- 分组逐模型倍率继续应用于 Token 计费、利润门和在途预留。用户专属倍率优先。密钥选组和模型广场保留倍率展示，模型广场也支持官方新增的复制模型 ID。
- HTTP Responses 和 WS 转 HTTP 共用 Codex 上下文处理，支持官方新增的 `ide_context`、`untrusted_content`、`proposed_plan`，以及二开的 `browser_tabs`。
- 保留自有在线升级、远程回退、安装和独立的官方版本提醒，以及固定版本 hotfix 工作流。[二开清单](../../DOWNSTREAM.md)

## 升级与发布

从 `v0.2.23-zy.2` 升级时没有新增 SQL 迁移。账号 Fast 设置仍读取 `accounts.extra`，分组逐模型倍率仍读取分组价卡中的 `group_rate_multiplier`。

正式发布使用 `v0.2.25-zy.1` tag 和完整 Release 工作流。在线升级使用该 Release 的安装包和校验文件，Docker 镜像版本为 `ghcr.io/zhiylee/sub2api:0.2.25-zy.1`。
