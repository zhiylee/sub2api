# v0.2.25-zy.2 发布说明

OpenAI 账号编辑页新增「强制使用 Ultra Fast」开关。模型和账号都符合资格时，HTTP 和 WebSocket 请求优先使用 Ultra Fast。其他请求按强制 Fast 设置或客户端档位处理，最终档位仍经过全局 Fast/Flex 策略。

「免费 Ultra Fast」可独立启用。启用后，最终以 Ultra Fast 转发的请求按 Standard 价格向客户扣费。

从 `v0.2.25-zy.1` 升级时，新增开关默认关闭，配置继续存放在 `accounts.extra`，无需新增数据库迁移。已有 WebSocket 会话需重连才能应用账号设置。

Docker 镜像为 `ghcr.io/zhiylee/sub2api:0.2.25-zy.2`。 [账号级 Fast 说明](../../backend/dev-docs/openai-account-fast.md)
