# v0.2.23-zy.1 集成说明

从官方 `v0.2.23`（`5af9afb588c4b014b3df9db7d4073af1f8ae01b6`）建立
`release/0.2.23`，迁入 `v0.2.21-zy.1` 的二开补丁。官方代码包含 v0.2.22 的改动。
[官方 v0.2.22](https://github.com/Wei-Shaw/sub2api/releases/tag/v0.2.22)、
[官方 v0.2.23](https://github.com/Wei-Shaw/sub2api/releases/tag/v0.2.23)

## 二开补丁

- 保留账号强制 Fast、免费 Fast 和 OpenAI 出站档位计费。分组 Ultra Fast 在上游模型及套餐符合资格时优先。免费 Fast 仅对最终以 `priority` 出站的请求生效。
- HTTP Responses 和 WS 转 HTTP 共用官方 Codex 上下文格式，保留 `browser_tabs` 兼容及实际工具调用结果。
- 保留来自 `zhiylee/sub2api` 的在线升级、回退和安装，以及独立的官方版本提醒。
- 官方 Go 1.27.4 覆盖原工具链补丁。补丁来源和退役记录见 [二开清单](../../DOWNSTREAM.md)。

## 数据库升级

从 `v0.2.21-zy.1` 升级时，启动阶段会按完整文件名应用以下官方迁移。

- `251_group_force_openai_ultrafast.sql` 添加分组强制 Ultra Fast 配置。
- `251_group_usage_rollup_nonblocking_build.sql` 更新分组日汇总的重建状态和失效函数。
- `252_channel_pricing_ultrafast_multiplier.sql` 添加可选的渠道 Ultra Fast 倍率。

正式部署前备份 PostgreSQL。回退程序或镜像只替换程序，恢复迁移前的数据库状态需要对应备份。
账号 Fast 配置继续使用 `accounts.extra`。
