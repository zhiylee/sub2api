# v0.2.21-zy.1 集成说明

基于官方 `v0.2.21`（`10ba8f9b4dc2e6023d4a9879ab77b21841babd10`），
将 `hotfix-v0.2.20-zy.2` 的已接纳二开及原工作区浏览器上下文修复迁到 `release/0.2.21`。
发布 tag 为 `v0.2.21-zy.1`，安装包和镜像以正式 Release 与发布流水线结果为准。

## 保留与调整

- 保留账号级「强制 Fast」和「免费 Fast」设置，继续与分组设置组合，并服从全局 Fast 策略。
- 保留 OpenAI 按最终出站档位计费，响应档位只作诊断；免费 Fast 仍只调整客户实际扣费。
- 官方已覆盖 HTTP Page 上下文，改为共享官方实现。二开补齐浏览器 ambient context 和每轮 WS 转 HTTP 的 Page / 浏览器处理。
- 继续保留固定版本 hotfix 镜像构建及程序版本校验，构建前回归包含上述上下文、Fast 和 TTL 计费。
- 新增 30m / 12h 缓存写入与账号免费 Fast 组合回归，验证实际用量记录和余额扣减。
- 后台升级和远程回退改用自有正式 Release，支持同一官方基线的 zy 修订更新，隔离历史官方缓存。
- 独立展示官方最新版本、发布时间和发布说明；官方有新版时在版本入口提示待同步，不进入安装决策。
- 手动回退命令及安装脚本改用自有渠道，Docker 命令使用自有 GHCR 固定版本镜像。

原分支和未提交改动保留在原工作区。补丁来源、迁移单元和退役依据见
[二开清单](../../DOWNSTREAM.md)。

## 官方升级注意

完整变更见[官方 v0.2.21 发布说明](https://github.com/Wei-Shaw/sub2api/releases/tag/v0.2.21)。

- 新增 `249_add_usage_logs_api_key_cost_index_notx.sql`：在 `usage_logs` 上并发建立覆盖索引，大表首次启动可能需要更长时间。
- 新增 `250_openai_cache_write_ttl.sql`：增加 OpenAI 30m / 12h 缓存写入用量及独立 12h 价卡字段；升级时自动执行。
- 请求体内存预算配置为 `gateway.request_body_memory_budget_bytes`。未配置时按物理内存、cgroup、GOMEMLIMIT 中的最小限制自动计算。
- 自定义价卡应确认通用缓存写入价与 12h 价格；新版增加缓存 TTL 区分，二开沿用官方定价逻辑。
- 二开本身没有新增配置键或数据库迁移，账号 Fast 配置仍使用已有的 `accounts.extra`。

## 自有升级渠道

正式发布使用 `v0.2.21-zy.1` 这类 tag，以及完整 Release 的平台安装包和 `checksums.txt`。
自有 zy 正式版明确标记为非预发布并进入 Latest；当前 simple 模式因缺少安装包而在构建前被拒绝。
单纯 hotfix 镜像不会成为后台可安装版本。
Release 页的一键安装命令使用该版本 tag 下的自有脚本，避免从 `main` 获取官方安装源。

首次切换需先部署包含本次改动的自有产物；旧程序仍保留它自身的升级源。
Docker 内在线更新仅改变当前容器中的程序，重建时仍使用镜像版本；常规升级应切换自有镜像并重建。
官方版本查询失败不影响自有更新检查或安装，自有更新源失败时不会回退到官方安装源。

实现边界及验收说明见[升级渠道说明](../../backend/dev-docs/downstream-update-channels.md)。
