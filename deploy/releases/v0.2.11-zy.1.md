## 升级注意

- API Key 创建限制默认开启：每用户最多 200 个有效 Key、每小时最多创建 60 次。
  配置项 `api_key_create.max_active_per_user` 和 `api_key_create.max_per_user_per_hour` 设为 0 可分别取消限制。
- 余额在途额度预占默认开启，低余额用户并发请求可能更早被拒绝。
  可通过 `billing.inflight_reservation.enabled: false` 关闭，或按配置示例调整参数。
- 从社区 `v0.2.9` 到 `v0.2.11` 没有新增数据库迁移。升级前仍应备份数据库与配置。

## 更新与部署

已安装 `v0.2.9-zy.1` 的实例可通过后台强制检测更新。后台更新只替换程序，
不会修改 Compose 的镜像版本；应将 Compose 同步到以下镜像并在维护窗口重建应用容器，
避免将来重建时恢复旧程序。首次从社区版迁移需手动切换镜像。

```text
ghcr.io/zhiylee/sub2api:0.2.11-zy.1
```

完整发布提供 Linux amd64/arm64、macOS amd64/arm64、Windows amd64 二进制及 `checksums.txt`；
GHCR 镜像支持 Linux amd64/arm64。
